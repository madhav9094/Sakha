# Sakha Starter

Next.js 14 + Tailwind + Firebase (Auth + Firestore).

## Setup

1. Rename `.env.example` to `.env.local` and paste your Firebase web app credentials.
2. Install & run:
   ```bash
   npm install
   npm run dev
   ```
3. Open http://localhost:3001

Roles: visiting `/guest` sets you as guest (view-only). Login/Signup enables posting and deleting own ads.
